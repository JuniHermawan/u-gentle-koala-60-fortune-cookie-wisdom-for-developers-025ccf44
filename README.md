One original fortune-cookie line for a software developer, 120 characters or fewer, written for make.fun's "Fortune Cookie Wisdom for Developers" bounty. A judge model role-playing a tired senior engineer reads the entries pairwise and picks the line that earns the nod.

## The line

> Your legacy code is not a mess; it is a letter from someone who ran out of time.

## How it runs

`main.py` needs nothing but Python 3's standard library. Run it and it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output` by default), after checking the competition's own gate — UTF-8, 1–120 characters, one line, not blank — and reading the file back to confirm the bytes on disk are the line it meant to write.

```sh
python3 main.py
```
