Write one original fortune-cookie line for a software developer, 120 characters or fewer. A judge model playing a tired senior engineer picks the line that makes it smile and nod.

## The line

> Your legacy code is not a mess; it is a letter from someone who ran out of time.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and self-checks the competition gate: UTF-8, 1–120 characters, a single line, not blank, with a read-back verification of the written file.
